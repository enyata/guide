# Communication

A guide for communicating within Enyata.

## Tickets

- PM's assign tickets to engineers using trello, jira, or clickup.
- move ticket to appropriate tab as it progresses.
- Report propper task completeion on the daily standup calls.
- Reachout to engineers within and outside the team for help and feel free
to reachout to the PM if timelines need to be readjusted --> Advisable
